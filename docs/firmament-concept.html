Firmament

A god game where you never touch the people. You command the sky and the ground: rain, drought, storm, fire. A civilization lives under it, adapts to it, and writes its history about you.

Design pillars

Three rules the whole game is built on

Indirect control

You have no units, no build menu and no orders. Every power acts on terrain or weather. People decide for themselves what to do about it.

Every act echoes

Each power has a short-term effect and a long-term one, and they usually point in opposite directions. A volcano burns a city and leaves the best farmland on the island.

They interpret you

The civilization builds a belief about the sky from what you have done to it. Kindness, cruelty and silence each produce a different culture, and that culture is your score.

Core loop

One turn of the world

The game runs in real time, but the simulation thinks in seasons. Each season runs the same four beats.

  1. 1

    Read the world

    Overlays show rainfall, fertility, hunger and belief. You see which village is starving before they know it.

  2. 2

    Shape the sky

    Spend divine energy on a power. Paint rain with a brush, drag a storm track, or place a disaster by hand.

  3. 3

    They adapt

    Villages harvest, starve, migrate, build levees or abandon the coast. The simulation decides, using needs and memory.

  4. 4

    History remembers

    The event is written into the chronicle and into culture. Belief toward you shifts, and faith refills your energy.

Development framework

How the game gets built

A simulation game lives or dies on whether the simulation can be trusted, tested and tuned. These four rules come before any feature work.

Rule A

Simulation owns the truth

All game state lives in one plain data object. The renderer only reads it and never changes it.

Rule B

Systems are pure steps

Each system takes state, events and a random source and returns new state. Every one can be unit-tested alone.

Rule C

Seeds replay everything

One seed plus a list of player actions rebuilds any run exactly. A bug report becomes a replay file.

Rule D

Tuning lives in data

Disasters, crops, tech unlocks and beliefs are JSON tables. Balancing never needs a code change.

Each layer reads only from the layers below it. The simulation runs in a Web Worker and posts a snapshot to the renderer after each tick, so a slow frame never slows the world and a heavy season never freezes the screen.

sim/tick.ts · the whole game in one function
export function tick(w: World, acts: Action[], rng: Rng): World {
  w = applyPowers(w, acts);  // player edits sky + ground
  w = climate(w, rng);        // season, wind, weather cells
  w = terrain(w);             // floods, ash fall, erosion
  w = ecology(w);             // soil, crops, forests
  w = society(w, rng);        // growth, hunger, migration
  w = culture(w);             // tech, belief, memory
  w.chronicle.push(...narrate(w.events));
  return w;
}

Visual art concept

Living Atlas

The world looks like a hand-tinted survey map that has started to breathe. Weather is ink wash drifting over the paper, and people are the only warm light on it.

Readable from orbit

Contour bands and hillshade make height obvious at a glance. You can tell fertile lowland from barren rock without opening an overlay.

Weather is translucent

Clouds are soft, semi-transparent washes with a cast shadow. They never hide the land completely, so you always see what your storm is doing.

People are light

Villages are the only warm color on the map. When they thrive they glow; when they die the light goes out and leaves a ring.

Type

An engraved serif for place names, chronicle text and headings, so the world reads like a carved record. A clean sans for the interface, and a monospace for dates and numbers.

Sound

Low drones for the sky that change with the weather. Small wooden and bell sounds for villages. Disasters arrive with silence first, then the sound.

Motion

The land never animates on its own. Only weather moves, and lights flicker. Change on the ground happens over seasons, so it feels earned.
