Firmament

A god game of indirect control. You command the weather over an archipelago. A civilization on the home island lives, adapts and invents under your sky, and the long test is whether it ever reaches the Far Shore.

Hybrid civilization

A crowd of numbers, and a few real people

Simulating every person in a 10,000-strong civilization for a thousand years is slow and hard to tune. Simulating only numbers loses the stories. Firmament does both, at three levels of detail.

Stored · always simulated

The crowd

Each village is one record: population, food, jobs, tech, belief and memory. This is what the simulation ticks every season.

  • Cheap to run at 100× speed
  • Easy to balance in data tables
  • Drives every decision a village makes
Drawn · only when zoomed in

The sample

When you zoom into a village, the game draws people from its numbers. If 30% of Aldmouth fishes, 30% of the figures walk to the boats.

  • Never saved, rebuilt on demand
  • Shows the record honestly
  • Costs nothing when you zoom out
Stored · individual agents

The named few

A handful of people are real agents with a name, age, goal, belief and memory. They are the faces of history: the raft-binder, the navigator, the captain.

  • About 3 per village, 30 in the world
  • Their choices can tip a village
  • They write the chronicle

When someone is promoted to a named agent

  • They are the first to do something: first crossing, first sail, first shrine.
  • The story needs a role filled: navigator, priest, founder, rebel.
  • They survive an event the village will remember.

What named agents can change

  • Speed up a tech: a navigator makes star navigation possible.
  • Shift belief: a priest teaches the village how to read your weather.
  • When they die they become a memory and a line in the chronicle.
The Far Shore test

Can they learn to cross the sea?

success = hull × navigation × weather × crew

// Year 760, the Long Breath sails east
hull        0.80  // outrigger + woven sail
navigation  0.55  // Kai has 30 nights of star counts
weather     0.90  // you held an east wind

success     0.28

Failure is how they learn

A lost boat raises the village's fear of the sea, but it also pushes hull and navigation research forward. Push them too hard and they stop sailing for a generation. Never test them and they never need to improve.

The Far Shore can also be found by accident: a fishing canoe blown east by a storm you sent. If the crew survives and comes home, the whole archipelago knows the Far Shore exists.

Core loop · indirect control

One turn of the world

You never give orders. The game runs in real time, but the simulation thinks in seasons, and each season runs the same four beats.

  1. 1

    Read the world

    Zoom from the whole archipelago down to one fisher. Overlays show rain, food, belief and who is planning a voyage.

  2. 2

    Shape the sky

    Spend divine energy on rain, wind, storm or drought. Paint it with a brush or drag a storm track.

  3. 3

    They adapt

    Villages harvest, starve, build boats or abandon the coast. Named people make their own choices inside that.

  4. 4

    History remembers

    The event goes into the chronicle and into belief. Faith refills your energy, so how they see you matters.

Development framework

How the game gets built

A simulation game lives or dies on whether the simulation can be trusted, tested and tuned. These four rules come before any feature work.

Rule A

Simulation owns the truth

All game state lives in one plain data object. The renderer only reads it and never changes it.

Rule B

Systems are pure steps

Each system takes state, events and a random source and returns new state. Every one can be unit-tested alone.

Rule C

Seeds replay everything

One seed plus a list of player actions rebuilds any run exactly. A bug report becomes a replay file.

Rule D

Detail on demand

Terrain detail and crowds are generated only for what is on screen. Zooming never changes the simulation.

Each layer reads only from the layers below it. The simulation runs in a Web Worker and posts a snapshot after each tick. The crowd sampler on the main thread turns village records into visible people, so the worker never stores them.

sim/tick.ts · the whole game in one function
export function tick(w: World, acts: Action[], rng: Rng): World {
  w = applyPowers(w, acts);  // player edits sky + ground
  w = climate(w, rng);        // season, wind, weather cells
  w = terrain(w);             // floods, silt, erosion
  w = ecology(w);             // soil, crops, forests, fish
  w = society(w, rng);        // villages: growth, hunger
  w = agents(w, rng);         // named people: goals, choices
  w = voyages(w, rng);        // boats at sea, discovery
  w = culture(w);             // tech, belief, memory
  w.chronicle.push(...narrate(w.events));
  return w;
}
sim/types.ts · core data model
interface Village {             // the crowd

Visual art concept

Living Atlas

The world looks like a hand-tinted survey map that has started to breathe. Weather is ink wash drifting over the paper, and people are the only warm light on it.

Readable from orbit

Contour bands, hillshade and sea depth make the island ladder obvious. You can see the shallow reef to Kelp Isle and the deep water before the Far Shore.

Detail grows as you zoom

Lights become roofs and fields, then trees and walking people. Clouds thin out as you go below them, so the ground is always readable.

People are light

Villages, figures and boats carry the warm colors. Named people get an ember ring so they stand out from the crowd.

Type

An engraved serif for place names, chronicle text and headings, so the world reads like a carved record. A clean sans for the interface, and a monospace for dates and numbers.

Sound

Low drones for the sky that change with the weather. Surf that grows louder as you zoom to the coast. Voices and tools at village zoom. Disasters arrive with silence first.

Motion

The land never animates on its own. Weather drifts, boats sail, people walk. Change on the ground happens over seasons, so it feels earned.
